POS Associated Service

Add an associated-service flow in Odoo POS for products that require optional or mandatory extra services.

Key Features

  • New fields on product.template: Tiene servicio asociado and Servicio asociado.
  • Service product selector restricted to products of type Service.
  • POS popup on each click of configured products.
  • Popup allows cashier to choose Quantity and Include associated service.
  • Independent decision on every click (no forced consolidation logic).
  • Works with standard POS order lines and pricing/tax behavior.

How It Works

  1. Configure the product in backend Sales tab.
  2. Enable Tiene servicio asociado.
  3. Select a service in Servicio asociado.
  4. In POS, when cashier clicks that product, the popup appears.
  5. Confirm to add product quantity and optional service quantity.
